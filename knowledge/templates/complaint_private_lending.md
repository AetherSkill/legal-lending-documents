# 民事起诉状（民间借贷纠纷）· 模板

> 编制依据：《最高人民法院、司法部、中华全国律师协会关于印发部分案件民事起诉状、答辩状示范文本（试行）的通知》（2024-03-04，11类44份，含民间借贷）
> 法律依据：《中华人民共和国民事诉讼法》第一百二十四条；生成后须在 flk.npc.gov.cn 复核现行文本

---

## 版本一：要素式（法院官方推荐，首选）

```
民事起诉状（民间借贷纠纷）

原告：[姓名]　性别：[__]　出生日期：[____]　民族：[__]　职业：[__]
住址：[__________]　身份证号：[__________]　联系电话：[__________]
被告：[姓名]　性别：[__]　出生日期：[____]　民族：[__]　职业：[__]
住址：[__________]　联系电话：[__________]

一、诉讼请求
1. 判令被告向原告偿还借款本金人民币____元；
2. 判令被告支付利息（以____元为基数，自____年__月__日起按年利率__%计算至实际清偿之日止，暂计至起诉之日为____元）；
3. 判令被告支付逾期利息/违约金____元（如有，且与其他费用合计不超过合同成立时一年期LPR四倍）；
4. 本案诉讼费、保全费由被告负担。

二、事实与理由（要素式）
□ 借款本金金额：____元；币种：人民币
□ 借款日期：____年__月__日
□ 交付方式：现金 / 银行转账 / 微信 / 支付宝 / 其他____
□ 约定利率：年利率____%（或无约定）
□ 约定还款日期：____年__月__日（或无固定期限）
□ 逾期利率/违约金：____（或无约定）
□ 已还金额：本金____元，利息____元（截至____年__月__日）
□ 合同效力排查：套取转贷/职业放贷/违法犯罪用途/公序良俗 等无效情形（无/有，见证据）
理由摘要：被告经催收仍未履行还款义务，已构成违约……

三、证据清单
1. 借条/借款合同（证明借贷合意及约定内容）
2. 转账凭证/银行流水（证明借款实际交付——自然人借贷自交付时成立）
3. 微信聊天记录/录音（证明催收及还款承诺）
4. 身份证/营业执照复印件（当事人主体资格）

此致
____人民法院

附：起诉状副本____份；证据副本____份
原告（签名/盖章）：__________
____年__月__日
```

## 版本二：叙述式（供律师改写/代理用）

```
民事起诉状（民间借贷纠纷）

原告：____（个人信息同上）
被告：____（个人信息同上）

诉讼请求：
1. 请求判令被告立即偿还原告借款本金人民币____元；
2. 请求判令被告支付利息人民币____元（计算方式：____）；
3. 请求判令被告支付逾期利息及违约金（以____元为基数，自____年__月__日起按____%计算）；
4. 本案诉讼费用由被告承担。

事实与理由：
原、被告系____关系。____年__月__日，被告因____向原告借款人民币____元，原告通过____方式交付。双方约定年利率__%、还款期限为____。
借款到期后，被告仅偿还____元，尚欠本金____元。原告多次催收，被告以____为由拒不归还。
依据《中华人民共和国民法典》第五百七十九条、第六百七十六条，以及《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》第二十五条等规定，被告应履行还款义务。为维护原告合法权益，特依据《中华人民共和国民事诉讼法》第一百二十二条向贵院提起诉讼，请依法裁判。

此致
____人民法院

具状人（签名）：__________
____年__月__日
```

## 生成规则（skill 必须执行）
1. **优先输出要素式**（对齐法院示范文本），叙述式作为补充。
2. **利率上限校验**：约定利率超过「合同成立时1年期LPR×4」的部分，在文书与提示中主动标注"超出部分不予支持"。
3. **交付凭证必核**：无借条或无交付凭证、金额较大时，输出结构化风险提示。
4. **时间分段**：2020-08-20 前成立的借贷，提示适用旧 24%/36% 规则。
5. **时效水印**：落款处自动加 `（本文书引用的LPR为____年__月公布值；法条以生成日现行有效文本为准）`。
6. **免责声明**：文末附 `AI生成文书，非法律意见，立案以受诉法院要求为准；重大案件建议咨询执业律师。`
